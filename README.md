# Cuidar da Nossa Vivência - Personal Page & Idea Hub

Uma página pessoal e portfólio desenvolvida para apresentar informações profissionais, projetos e criar um canal direto de interação para envio de ideias e sugestões.

## 🚀 Funcionalidades

- **Apresentação Pessoal:**
  - Perfil com foto, biografia resumida e citação inspiradora.
  - Seções organizadas para **Sobre Mim**, **Projetos** e **Contato**.

- **Modal "Registrar Ideia":**
  - Janela pop-up interativa para que visitantes ou colaboradores possam enviar ideias, sugestões ou insights diretamente pela plataforma.

- **Design Minimalista e Clean:**
  - Interface moderna, responsiva e focada na experiência do usuário (UX).

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica da página e componentes do modal.
- **CSS3:** Estilização com layout limpo, sombras suaves e estados de foco/sobreposição.
- **JavaScript:** Lógica de abertura/fechamento do modal e envio dos formulários de ideias.
